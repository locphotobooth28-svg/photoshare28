# PhotoShare 28 V3

Deux accès uniquement :

## Invités
- QR Code / lien invité
- ajout photos et vidéos
- consultation galerie
- aucun bouton Télécharger

## Organisateur
- lien privé unique
- consultation complète
- téléchargement individuel
- téléchargement de toute la galerie en ZIP
- QR Code et lien invité à partager

## Durée
Accès invité + organisateur pendant 30 jours après la date de l'événement.

## Google Drive
OAuth 2.0 uniquement :
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_REFRESH_TOKEN
- GOOGLE_DRIVE_ROOT_FOLDER_ID

## Important
Une page web ne peut pas empêcher réellement une capture d'écran. V3 désactive seulement le clic droit/glisser et ne fournit aucun bouton de téléchargement côté invité.

## Installation
Décompresser l'archive et remplacer les fichiers du dépôt GitHub par ceux-ci.
Render redéploiera automatiquement.
